This is a very common GitHub Pages issue, especially with React / Vite apps. Don’t worry — we’ll cleanly remove the broken gh-pages branch and redeploy from scratch so it works like before.

I’ll give you safe, step-by-step commands you can run from VS Code terminal 👇

🧹 STEP 1: Delete gh-pages branch from GitHub (remote)

Open VS Code → Terminal in your project root and run:

git push origin --delete gh-pages


✔ This removes the broken gh-pages branch from GitHub
✔ Your main branch is NOT affected

If GitHub says branch doesn’t exist — that’s fine.

🧼 STEP 2: Delete local gh-pages branch (if exists)
git branch -D gh-pages

⚙️ STEP 3: Reset GitHub Pages settings

Go to GitHub repo → Settings → Pages

Under Source, select:

Deploy from a branch

Set:

Branch: main

Folder: /docs ❌ (don’t use this)

Click Save

Then disable Pages (select “None”) and save once
👉 This clears cached config

🧱 STEP 4: Fix React / Vite config (VERY IMPORTANT)
✅ vite.config.ts / vite.config.js
import { defineConfig } from 'vite'
import react from '@vitejs/plugin-react'

export default defineConfig({
  plugins: [react()],
  base: '/REPO_NAME/',   // 👈 exact GitHub repo name
})


Example:

base: '/portfolio/'


❗ If this is wrong → blank page

📦 STEP 5: Install & configure gh-pages (if not installed)
npm install gh-pages --save-dev

Update package.json
{
  "homepage": "https://<username>.github.io/<repo-name>",
  "scripts": {
    "build": "vite build",
    "deploy": "gh-pages -d dist"
  }
}

🚀 STEP 6: Build & Deploy fresh gh-pages
npm run build
npm run deploy


✔ This:

Builds your app

Creates a new clean gh-pages branch

Pushes only production files

🌐 STEP 7: Enable GitHub Pages correctly

GitHub → Settings → Pages

Source:

Branch: gh-pages

Folder: / (root)

Save

⏳ Wait 1–2 minutes

✅ Final URL
https://<username>.github.io/<repo-name>/
